# Brief: Halaman Detail Program Scareer

Template halaman untuk **semua program** di `/program/[slug]`. Struktur section mengikuti diagram dari tim dan tidak diubah. Gaya UI mengikuti `Design-Homepage-Scareer-Variant-Structured.md`. Wireframe pendamping ada di canvas terpisah dan memakai nomor catatan yang sama dengan bagian 7.

Semua fakta program yang belum ada ditulis `[ISI]`. Contoh judul dan copy di brief ini adalah **arah**, bukan copy final. Setiap klaim tentang program harus dikonfirmasi tim sebelum tayang.

---

## 1. Peran halaman

Homepage membantu orang menemukan dan percaya. **Halaman detail membantu orang memutuskan.** Pengunjung yang sampai di sini sudah tertarik pada satu bidang dan sedang menimbang: isinya apa, siapa yang mengajar, kapan mulai, berapa biayanya, dan apakah ini cocok untukku.

| Aspek | Isi |
| --- | --- |
| Tujuan utama | Pengunjung memilih paket lalu melanjutkan ke WhatsApp untuk mendaftar. |
| Tujuan sekunder | Mengunduh silabus. Bertanya dulu lewat WhatsApp. |
| Audiens | Fresh graduate, pencari kerja entry-level, career switcher pemula. Budget terbatas. Mayoritas dari HP. |
| Posisi | Kakak tingkat: jujur soal isi, jadwal, dan biaya. Murah, bukan murahan. Didukung Dibimbing. |
| Metrik keberhasilan | Klik "Pilih paket" per paket dan mode bayar, unduhan silabus, klik WhatsApp per sumber, kedalaman scroll sampai Harga, FAQ yang dibuka. |
| Pendaftaran | Lewat WhatsApp. Tidak ada form pendaftaran atau checkout di halaman ini. |

## 2. Pertanyaan yang harus terjawab, urut seperti pikiran calon peserta

1. Ini program apa dan buat siapa? (Hero)
2. Kenapa aku perlu ini? Masalahnya benar-benar masalahku? (Problem Agitate Solution)
3. Kenapa Scareer dan kenapa program ini? (Why Us)
4. Aku belajar apa saja, dan berapa lama? (Curriculum)
5. Pakai alat apa? Aku bisa mengoperasikannya? (Tools)
6. Setelah selesai, aku bisa apa dan membawa pulang apa? (Skills & Output)
7. Siapa yang mengajar? Mereka orang industri atau bukan? (Mentor)
8. Alurnya bagaimana, kapan mulai, jadwalnya cocok nggak? (Journey & Schedule)
9. Seperti apa hasil karya yang dibuat? (Portfolio Output)
10. Detail teknisnya apa, dan program ini cocok untuk orang sepertiku? (Program Detail → Untuk siapa)
11. Berapa biayanya, bisa dicicil, apa bedanya paket? (Pricing)
12. Sisa keraguanku dijawab di mana? (FAQ)

### 3.3 Pola struktur halaman bootcamp sejenis (sebagai pembanding)

Halaman bootcamp Dibimbing memuat latar belakang program, alasan memilih, alur bootcamp (persiapan mandiri, fase inti, fase persiapan karier dengan durasi masing-masing), siapa yang cocok (pemula, career switcher, profesional), prospek karier, mentor, tempat alumni bekerja, testimoni, dan layanan persiapan karier. Struktur dari tim sudah mencakup sebagian besar kebutuhan ini. Dua hal yang **tidak** ada di struktur dan sengaja tidak ditambahkan: testimoni terpisah dan section prospek karier. Keduanya bisa masuk ke dalam Why Us (prospek karier, jika ada sumber terverifikasi) dan Portfolio Output (karya), tanpa mengubah struktur.

## 4. Prinsip konten

1. **Jujur lebih penting dari meyakinkan.** Halaman ini boleh menulis "mungkin belum cocok kalau...".
2. **Satu fakta, satu sumber.** Semua angka, tanggal, harga, dan nama diambil dari data program, tidak diketik ulang di banyak tempat.
3. **Tidak ada janji kerja, penempatan, gaji, atau persentase hasil** kecuali tim punya data terverifikasi dan menuliskan definisinya.
4. **Label jujur untuk semua bukti.** Karya: "Dikerjakan peserta batch [ISI]" atau "Contoh dari tim mentor". Mentor: hanya orang yang benar-benar mengajar program ini.
5. **Tidak ada visual atau bahasa diskon.** Tidak ada harga dicoret, hitung mundur, "kuota tinggal 3" tanpa data nyata.
6. **Nada kakak tingkat:** "kami" dan "kamu", santai tapi rapi, tidak mengguru.
7. **Hanya fakta yang bisa diverifikasi pembaca.** Kalau belum ada, tulis `[ISI]` di brief dan hapus section/butirnya dari halaman produksi.

## 6. Navigasi halaman

Halaman ini panjang (12 section), jadi ada daftar isi yang selalu terjangkau dan bisa menggulung otomatis ke section tujuan. Ini elemen navigasi, bukan section, jadi tidak mengubah struktur.

- **Breadcrumb:** Beranda › Program › [Nama Program]. "Program" menaut ke `/program`.
- **Daftar isi: 12 item dalam 4 grup.** Label singkat (maksimal dua kata) dan mengikuti urutan section.

| Grup | Item | Section asal | Anak (muncul saat induk aktif) |
| --- | --- | --- | --- |
| Kenali | Ringkasan | Hero | - |
| | Masalah dan solusi | Problem Agitate Solution | - |
| | Kenapa kami | Why Us | Kenapa Scareer, Kenapa program ini |
| Isi program | Kurikulum | Curriculum | - |
| | Tools | Tools | - |
| | Skill dan output | Skills & Output | - |
| | Mentor | Mentor | - |
| Jalani | Jadwal | Journey & Schedule | - |
| | Karya | Portfolio Output | - |
| | Detail program | Program Detail | Untuk siapa |
| Daftar | Harga | Pricing | - |
| | FAQ | FAQ | - |

**Tiga pola menurut lebar layar** (wireframe lengkap ada di board "Navigasi samping"):

| Lebar viewport | Pola |
| --- | --- |
| 1440 px ke atas | **Sidebar penuh** 200 px di gutter kiri, di luar kolom konten 1024 px, sehingga tata letak tidak bergeser. Sticky di top 96 px. Berisi daftar isi, jalur progres, dan kartu CTA mini ("Mulai dari Rp [ISI]" + "Lihat paket"). |
| 1280 sampai 1439 px | **Rail** 56 px (garis kecil per item, chip nama pada item aktif). Melebar jadi panel 220 px yang melayang saat hover, fokus, atau klik, tanpa menggeser konten. |
| Di bawah 1280 px (HP dan tablet) | **Section switcher** 52 px di bawah navbar (nama section aktif, "4 dari 12", garis kemajuan) yang membuka **bottom sheet** berisi daftar isi lengkap. |

**Perilaku**
- **Klik item = smooth scroll otomatis** ke judul section. Offset 96 px di desktop dan 124 px di HP (navbar + switcher + 16 px). Hash URL diperbarui (`pushState` saat klik, `replaceState` saat scroll biasa). Fokus keyboard pindah ke judul section.
- **Scroll-spy** memakai satu IntersectionObserver (bukan event scroll). Section aktif adalah yang melewati garis 40% dari atas viewport. Bila halaman mentok di dasar, FAQ otomatis aktif. Selama gulungan akibat klik berjalan, scroll-spy dikunci agar item tidak berkedip.
- **Indikator aktif** bergeser 200 ms. Item anak membuka dan menutup 200 ms mengikuti induknya.
- **Di atas section gelap** (Why Us dan Portfolio Output), warna sidebar berganti ke versi on-ink (150 ms).
- **Kartu CTA mini** tersembunyi saat Hero atau Harga terlihat.
- **Bar CTA sticky (HP saja):** "Lihat paket", tersembunyi saat Hero atau Harga terlihat.
- Tombol WhatsApp mengambang tidak dipakai.
- **Aksesibilitas:** `<nav aria-label="Daftar isi halaman">` dengan daftar berurutan dan tautan biasa, `aria-current="location"` pada item aktif, tanpa `aria-live` untuk perubahan scroll-spy, tautan "Lewati daftar isi", dan perilaku reduced motion (indikator berpindah tanpa animasi, scroll instan).
- **Pelacakan:** `toc_click` dengan `section` dan `sumber` (sidebar, rail, atau sheet).

## 7. Brief per section

Tiap section memuat: tujuan, isi wajib, arah copy, data yang dibutuhkan, komponen UI, CTA, perilaku, dan yang tidak boleh. Nama komponen merujuk ke dokumen desain.

### 7.1 Hero

**Tujuan.** Dalam 5 detik, pengunjung tahu program apa ini, untuk siapa, dan apa langkah berikutnya.

**Isi wajib**
- Breadcrumb.
- H1 dengan **nama program memimpin** (untuk SEO dan kejelasan), contoh: "Bootcamp [Nama Program]". Brand hook tidak dipakai di H1 halaman ini.
- Subhead 1–2 kalimat: untuk siapa + hasil konkret (contoh arah: "Belajar [bidang] dari dasar bareng mentor, dan pulang bawa portofolio.").
- Lencana: "Didukung Dibimbing", format, durasi.
- Dua tombol: **"Lihat paket"** (utama, menggulung ke Harga) dan **"Tanya via WhatsApp"**.
- Baris centang: "Cicilan tersedia", "Bisa ngobrol dulu", "Didukung Dibimbing".
- **Panggung:** foto kelas atau mentor asli dengan **kartu ringkasan program** di atasnya (durasi, format, mulai batch berikutnya, level, "mulai dari Rp [ISI]"). Menggantikan peran kartu lowongan di homepage.
- Strip fakta berborder: durasi, jumlah sesi, format, kuota batch.

**Data dibutuhkan.** Nama program, bidang, durasi, format, tanggal mulai batch terdekat, harga mulai, foto kelas.

**Komponen.** Hero rata kiri + panggung, tombol pil, baris centang, strip bukti (sel berborder), kartu ringkasan.

**Perilaku.** "Lihat paket" smooth scroll ke #harga. Kartu ringkasan statis (tanpa animasi masuk). Tanggal batch memakai data nyata dan otomatis hilang jika sudah lewat. Tanpa auto-scroll dan tanpa parallax.

**Jangan.** Janji kerja, "terbaik", harga dicoret, hitung mundur.

### 7.2 Problem Agitate Solution

**Tujuan.** Pengunjung merasa "ini masalahku" lalu melihat jalan keluar yang masuk akal. Singkat: satu layar.

**Isi wajib: tiga kolom**
| Kolom | Isi | Arah copy |
| --- | --- | --- |
| Problem | Masalah konkret yang dihadapi calon peserta di bidang ini. | "Lowongan [posisi] bilang fresh graduate welcome, tapi syaratnya pengalaman 2 tahun." |
| Agitate | Akibat jika dibiarkan, tanpa dramatisasi berlebihan. | "Belajar sendiri dari tutorial, tapi nggak tahu arahnya benar atau nggak. Portofolio kosong, CV pun terasa kosong." |
| Solution | Pendekatan program ini, dalam satu kalimat. | "Belajar bareng mentor, kerjakan proyek nyata, pulang bawa portofolio." (**perlu dikonfirmasi tim**) |

- Opsional: **satu** statistik bersumber dari bagian 3.1, dengan tautan sumber dan tahun, misalnya durasi tunggu pencari kerja 19,8 bulan (LPEM FEB UI, data Sakernas Agustus 2025). Dibatasi ke "pencari kerja", jangan ditulis khusus fresh graduate.
- Kalimat pernyataan rata tengah di atas tiga kolom, dengan maksimal tiga kata kunci diberi stabilo.

**Komponen.** Kalimat pernyataan dengan stabilo + baris tiga pilar bergaris vertikal.

**Perilaku.** Statis. Tanpa animasi masuk dan tanpa hover.

**Jangan.** Menakut-nakuti, menyalahkan pembaca, memakai statistik tanpa sumber.

### 7.3 Why Us

**Tujuan.** Menjawab "kenapa Scareer" secara ringkas dan "kenapa program ini" secara spesifik.

**Anak section 1: Kenapa Brand (ringkas, 3 butir)**
- Kakak tingkat, bukan institusi: dibimbing orang yang paham rasanya cari kerja.
- Didukung Dibimbing: peran Dibimbing yang benar-benar ada [ISI].
- Murah, bukan murahan: yang dikurangi, yang tidak, dan **yang nggak kami janjikan** (tidak menjanjikan kerja).
- Tautan teks "Pelajari Scareer" ke bagian Kenapa Scareer di homepage.

**Anak section 2: Kenapa Program Ini (3 sampai 4 butir, spesifik program)**
- Relevansi bidang: permintaan atau peran yang dituju. **Hanya jika ada sumber terverifikasi dan tahunnya.** Jika tidak ada, butir ini dibuang.
- Belajar lewat proyek: jumlah proyek dan jenisnya [ISI].
- Tools yang dipakai di industri [ISI] (menaut ke Tools).
- Mentor praktisi aktif (menaut ke Mentor).

**Komponen.** Panel gelap bergrid: dua kelompok sel di atas Ink (`--ink-raised`, border `--border-on-ink`). Sel "yang nggak kami janjikan" selalu tampil utuh.

**Perilaku.** Statis. Tanpa hover.

**Jangan.** Klaim perbandingan dengan bootcamp lain tanpa dasar. Menyebut angka alumni tanpa definisi.

### 7.4 Curriculum

**Tujuan.** Menunjukkan isi belajar sejelas mungkin. Ini section yang paling dicari calon peserta sebelum memutuskan.

**Isi wajib**
- Ringkasan: total durasi, jumlah modul, jumlah proyek, jam belajar per minggu.
- Daftar **modul berurutan**. Tiap modul: nama, durasi (minggu atau pertemuan), topik (3–6 butir), tools, dan **output** modul (apa yang dihasilkan peserta).
- Penanda modul yang menghasilkan proyek portofolio.
- **CTA Download File:** "Unduh silabus lengkap (PDF)". Tampilkan nama file, ukuran, dan tanggal pembaruan. Unduhan langsung tanpa form. Alternatif teks kecil: "Mau silabus lewat WhatsApp?".

**Data dibutuhkan.** Silabus final per program, file PDF, tanggal pembaruan kurikulum.

**Komponen.** Tab vertikal dengan panel: daftar modul di kiri, rincian modul di kanan. Mobile: akordeon.

**Perilaku.** Klik, Enter, atau panah atas/bawah memilih modul. Tidak berpindah otomatis. Panel crossfade 200 ms. Unduh membuka berkas di tab baru atau mengunduh langsung dan mengirim event pelacakan.

**Jangan.** Daftar topik tanpa durasi dan output. Kurikulum yang tidak sama dengan silabus PDF.

### 7.5 Tools

**Tujuan.** Pengunjung tahu alat apa yang akan dipakai dan bahwa ia akan diajari dari dasar.

**Isi wajib.** Daftar tools dikelompokkan per kategori. Tiap tool: nama, fungsi singkat ("dipakai untuk..."), level pengenalan (dasar atau menengah), modul tempat dipakai.

**Komponen.** Grid sel berborder (4 kolom desktop), ikon atau logo tool, filter kategori opsional.

**Perilaku.** Statis. Sel tidak bisa diklik kecuali menaut ke modul terkait di Curriculum (smooth scroll dan modul terpilih).

**Jangan.** Memakai logo merek sehingga terkesan kemitraan resmi kecuali ada izin dan panduan merek. Jika tidak, gunakan nama teks dan ikon generik.

### 7.6 Skills & Output

**Tujuan.** Menjawab "setelah selesai aku bisa apa dan membawa pulang apa".

**Isi wajib: tabel tiga kolom**
| Skill yang dikuasai | Bukti: kamu bisa... | Output yang dibawa pulang |
| --- | --- | --- |
| [Skill 1] | [Hal konkret yang bisa dilakukan] | [Artefak: proyek, dokumen, dashboard, dll.] |

- Pisahkan **hard skill** dan **soft skill**.
- Daftar output yang bisa dibawa pulang: portofolio, sertifikat (hanya jika ada dan syaratnya jelas), review CV [ISI], akses materi [ISI].
- Opsional: kolom "sering diminta di lowongan". Hanya boleh diisi jika tim sudah memeriksa sejumlah lowongan nyata dan mencatat jumlah sampelnya.

**Komponen.** Tabel bergaris (hairline) dalam kontainer berradius 20 px. Mobile: ditumpuk per skill.

**Perilaku.** Statis. Baris dengan modul terkait menaut ke Curriculum.

**Jangan.** Janji hasil seperti "pasti dapat kerja" atau rentang gaji tanpa sumber.

### 7.7 Mentor

**Tujuan.** Membuktikan bahwa yang mengajar adalah praktisi, dan menjelaskan bagaimana peserta mengakses mereka.

**Isi wajib per mentor.** Foto asli, nama, peran dan perusahaan saat ini [ISI], lama pengalaman, bidang keahlian, peran di program (kelas live, review proyek, sesi 1-on-1), dan persetujuan tampil.
**Isi wajib section.** Bentuk akses ke mentor (jumlah sesi live, 1-on-1, respons review) dan rasio mentor:peserta jika ada.

**Komponen.** Dua kartu mentor unggulan (potret miring, bergantian kiri/kanan) dan baris kartu kecil untuk mentor lain. Fakta mentor dipisah garis vertikal.

**Perilaku.** Statis. Tanpa hover dan tanpa carousel auto-play. Jika mentor lebih dari enam, tampil dengan grid yang bisa digeser di mobile.

**Jangan.** Memajang mentor yang tidak mengajar program ini. Menulis pengalaman tanpa konfirmasi mentor. Kutipan palsu.

### 7.8 Journey & Schedule

**Tujuan.** Pengunjung bisa membayangkan perjalanannya dan mengecek kecocokan jadwal.

**Isi wajib: dua bagian**
1. **Alur belajar:** fase berurutan dengan durasi tiap fase (arah: persiapan, belajar inti dengan proyek, portofolio dan persiapan karier). Nama dan durasi fase final dari tim `[ISI]`. Pola tiga fase hanyalah usulan struktur.
2. **Jadwal batch:** tabel batch yang sedang atau akan dibuka. Kolom: nama batch, tanggal mulai, hari dan jam kelas, format (online atau offline, lokasi jika offline), kuota, status (pendaftaran dibuka, hampir penuh, penuh).

**Komponen.** Timeline bersel (garis penghubung tipis) + tabel jadwal bergaris. Mobile: fase ditumpuk vertikal dengan garis putus-putus, jadwal menjadi kartu per batch.

**Perilaku.** Status batch dibaca dari data. "Hampir penuh" dan "penuh" hanya tampil jika datanya nyata. Tombol kecil per batch "Tanya jadwal via WhatsApp" membawa nama batch ke pesan.

**Jangan.** Kelangkaan palsu. Jadwal yang sudah lewat tetap tampil.

### 7.9 Portfolio Output

**Tujuan.** Menunjukkan seperti apa hasil karya, sehingga janji "pulang bawa portofolio" terlihat nyata.

**Isi wajib per karya.** Gambar atau tangkapan layar, judul proyek, peran peserta, tools, ringkasan satu kalimat, dan **label jujur** ("Dikerjakan peserta batch [ISI]" atau "Contoh dari tim mentor"). Tautan ke detail atau pratinjau jika ada izin.

**Jika belum ada karya peserta:** tampilkan "Proyek yang akan kamu kerjakan" dengan contoh buatan tim mentor, diberi label jelas. Tidak ada karya karangan.

**Komponen.** Akordeon foto 5 kolom (desktop) yang melebar saat hover atau fokus. Mobile: carousel scroll-snap dengan kartu berikutnya mengintip.

**Perilaku.** Hover atau fokus melebarkan kolom (300 ms), menampilkan deskripsi dan label. Klik membuka detail atau pratinjau. Tanpa auto-scroll. Nama dan label sudah ada di DOM tanpa hover.

**Jangan.** Memakai karya milik pihak lain. Menampilkan karya peserta tanpa izin tertulis.

### 7.10 Program Detail dan "Program ini untuk siapa"

**Tujuan.** Menjawab detail teknis lalu membantu pengunjung menilai kecocokan dirinya, termasuk saat jawabannya "belum".

**Program Detail: spesifikasi**
| Item | Isi |
| --- | --- |
| Level | [ISI] |
| Durasi total | [ISI] |
| Waktu belajar per minggu | [ISI] jam |
| Format | Online live atau offline [ISI] |
| Bahasa pengantar | [ISI] |
| Perangkat dan spesifikasi minimum | [ISI] |
| Prasyarat | [ISI] (atau "tanpa prasyarat") |
| Akses materi dan rekaman | [ISI] |

**Anak section: Program ini untuk siapa.** Tiga kartu persona (misalnya fresh graduate, career switcher, pemula tanpa latar belakang). Tiap kartu: "Cocok kalau kamu..." (2–3 butir) dan "Mungkin belum cocok kalau..." (1–2 butir). Penutup: "Masih ragu? Ngobrol dulu" dengan chip tanya cepat ("Aku [persona], cocok nggak?").

**Perilaku.** Statis. Chip tanya cepat membuka WhatsApp dengan pesan awal berisi persona.

**Jangan.** Menjanjikan bahwa program cocok untuk semua orang.

### 7.11 Pricing

**Tujuan.** Harga yang transparan dan pilihan paket yang mudah dipahami, lalu satu langkah menuju WhatsApp.

**Isi wajib**
- **Dua paket: Professional dan Career Acceleration.** Tiap paket: nama, untuk siapa (satu kalimat), isi yang termasuk (daftar centang), dan yang **tidak** termasuk.
- **Dua pilihan bayar untuk tiap paket: Full Price dan Cicilan.** Pengunjung memilih mode bayar lewat toggle, harga di kedua paket berubah.
  - *Full Price:* total harga, apa yang termasuk.
  - *Cicilan:* tenor, nominal per bulan, **total yang dibayar di akhir**, biaya admin atau bunga bila ada, penyedia cicilan, dan syarat singkat.
- **Tabel perbandingan paket** (satu baris per fitur, centang atau angka): durasi akses, jumlah sesi live, mentoring 1-on-1, review proyek, portofolio, dukungan karier (review CV dan LinkedIn, simulasi wawancara), sertifikat, akses rekaman, komunitas. Isi tiap sel `[ISI]` dari tim.
- Kebijakan pengembalian dana atau pindah batch `[ISI]`, dituliskan jelas dalam bahasa sederhana.
- **CTA "Pilih paket"** per paket: membuka WhatsApp dengan pesan awal berisi program, paket, dan mode bayar.
- Satu baris di bawah: "Belum yakin pilih yang mana? Tanya dulu" (chip tanya cepat: "Bedanya Professional dan Career Acceleration apa?").

**Data dibutuhkan.** Harga per paket, skema cicilan (penyedia, tenor, biaya), kebijakan refund, isi tiap paket.

**Komponen.** Toggle mode bayar + dua sel paket dalam satu kontainer berradius, tabel perbandingan bergaris, tombol pil utama per paket.

**Perilaku.** Toggle memperbarui harga dengan crossfade 150 ms tanpa pergeseran layout (tinggi kartu tetap). Pilihan mode disimpan di URL (`?bayar=cicilan`) agar bisa dibagikan. Tombol "Pilih paket" menyusun pesan WhatsApp dan membawa sumber. Tidak ada form atau checkout.

**Jangan.** Harga dicoret, label "paling laris" tanpa data, hitung mundur, biaya tersembunyi, cicilan yang hanya menampilkan angka bulanan tanpa total.

### 7.12 FAQ

**Tujuan.** Menghilangkan keraguan terakhir tanpa membuat orang keluar halaman.

**Pertanyaan yang disarankan (spesifik program)**
1. Apakah perlu pengalaman atau latar belakang tertentu?
2. Spesifikasi laptop yang dibutuhkan?
3. Berapa jam belajar per minggu? Bisa sambil kuliah atau kerja?
4. Bagaimana kalau aku ketinggalan sesi?
5. Apa bedanya paket Professional dan Career Acceleration?
6. Bagaimana skema cicilan dan apa saja syaratnya?
7. Bagaimana kebijakan refund atau pindah batch?
8. Apakah ada jaminan kerja? (Jawaban jujur: tidak menjanjikan, dan apa yang tetap kami bantu `[ISI]`.)
9. Apakah dapat sertifikat?
10. Bagaimana cara daftar dan bayar?

**Komponen.** FAQ bergaris dengan judul sticky di kiri (desktop). Jawaban di bawah 60 kata. Di bawah daftar: "Pertanyaanmu belum ada di sini?" dan tombol WhatsApp.

**Perilaku.** Klik membuka dengan animasi tinggi 250 ms. Boleh beberapa terbuka. Deep-link `#faq-nama` membuka butir terkait.

**Jangan.** Jawaban yang mengulang marketing. Jawaban yang menghindari pertanyaan.

## 12. Keputusan terbuka

1. **Pendaftaran:** semua lewat WhatsApp, atau ada langkah konfirmasi tertulis sebelum bayar? Kebijakan refund harus jelas sebelum halaman tayang.
2. **Unduh silabus:** tanpa form (disarankan, karena tidak ada infrastruktur form) atau meminta nomor WhatsApp dulu?
3. **Prospek karier dan gaji:** dipakai atau tidak? Jika ya, harus ada sumber terverifikasi dan tahunnya. Jika tidak, tidak ditampilkan.
4. **Isi paket:** apa pembeda Professional dan Career Acceleration? Kerangka perbandingan di 7.11 sudah siap, nilainya belum ada.
5. **Hasil alumni:** belum ada data nyata, jadi tidak ditampilkan. Kalau nanti ada, definisinya (jumlah, periode, cara verifikasi) harus ditulis di samping angkanya.
6. **Karya peserta:** jika belum ada alumni, Portfolio Output memakai contoh karya tim mentor yang diberi label jelas. Setuju?
7. **Jaminan kerja:** konfirmasi bahwa Scareer tidak menjanjikan kerja. Jawaban FAQ ditulis sesuai kebijakan ini.

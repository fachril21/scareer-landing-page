# Struktur Homepage Scareer

Oct 12, 2026 · @Fachril

## Tujuan dan asumsi

Homepage Scareer bertugas **mengenalkan brand dan mengarahkan pengunjung ke halaman detail bootcamp yang tepat**. Keputusan ikut program diambil di halaman detail, bukan di homepage. Jadi homepage cukup menjawab: Scareer itu apa, kenapa bisa dipercaya, program apa saja yang ada, dan mulai dari mana.

| Aspek           | Isi                                                                                                             |
| --------------- | --------------------------------------------------------------------------------------------------------------- |
| Tujuan utama    | Pengunjung membuka salah satu halaman detail bootcamp                                                           |
| Tujuan sekunder | Pengunjung yang belum yakin mengobrol dulu lewat WhatsApp                                                       |
| Audiens         | Fresh graduate, pencari kerja entry-level, dan mungkin career switcher pemula, dengan budget terbatas           |
| Posisi brand    | Teman setara, "kakak tingkat". Bootcamp terjangkau (sekitar Rp4 juta), didukung Dibimbing. Murah, bukan murahan |
| Tone            | Jujur, hangat, relatable, santai, percaya diri. Kami = brand, kamu = pembaca                                    |

**Asumsi yang dipakai** (perlu dikonfirmasi, lihat bagian terakhir):

- Scareer punya **banyak program bootcamp** (sudah dikonfirmasi). Karena itu homepage hanya memajang program unggulan, dan ada halaman Daftar program untuk semuanya.
- Belum ada testimoni atau alumni yang bisa dipublikasikan. Cerita peserta dibuat **bersyarat**: tampil hanya jika datanya nyata.
- Pendaftaran dan konsultasi lewat WhatsApp, seperti di halaman detail. Belum ada form pendaftaran atau checkout.
- Semua angka dan fakta program tetap `[ISI]`, tidak dikarang.

## Peran homepage dan halaman detail

Supaya tidak ada isi yang dobel, pembagiannya begini: homepage untuk **menemukan dan percaya**, halaman detail untuk **memutuskan**.

| Aspek                   | Homepage                                                                       | Halaman detail bootcamp                                                      |
| ----------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Pertanyaan yang dijawab | Scareer itu apa? Bisa dipercaya? Ada program apa?                              | Program ini apa isinya, siapa yang membimbing, kapan mulai, berapa biayanya? |
| Kedalaman               | Ringkas, satu layar per ide                                                    | Rinci: kurikulum, tools, jadwal, harga tiap paket                            |
| H1 dan SEO              | Brand: Scareer dan hook "fresh graduate, tapi diminta pengalaman 2 tahun"      | Nama program memimpin                                                        |
| Bagian brand            | Dikenalkan penuh (kakak tingkat, kenapa lebih murah, yang nggak kami janjikan) | Cukup ringkas                                                                |
| Harga                   | Hanya "mulai dari" dan prinsip transparan                                      | Harga tiap paket, cicilan, perbandingan                                      |
| CTA utama               | Lihat program                                                                  | Pilih paket, lanjut ke WhatsApp                                              |
| Mentor dan karya        | Sorotan lintas program                                                         | Milik program itu saja                                                       |
| Navigasi                | Menu situs                                                                     | Menu situs + breadcrumb + sub-nav antar-section                              |

## Struktur homepage

Dipadatkan jadi **7 section isi + navbar dan footer** (sebelumnya 14). Urutannya mengikuti cara orang memutuskan: dipahami dulu, lihat pilihan, dipercaya, lalu diajak bergerak. **Program di urutan ke-3**, karena tujuan utama homepage adalah mengantar ke halaman detail.

| #   | Section                    | Tujuan                                          | Isi inti                                                                                                                                                                                                                                                       | CTA atau tautan                                             |
| --- | -------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 1   | Navbar                     | Navigasi situs                                  | Logo, Program (dropdown daftar program), Kenapa Scareer, FAQ, tombol "Lihat program"                                                                                                                                                                           | Lihat program                                               |
| 2   | Hero                       | Menjawab "ini apa dan buat siapa" dalam 5 detik | H1 hook brand ("Fresh graduate, tapi diminta pengalaman 2 tahun?"), subhead yang menyebut masalah dan janji jujur, badge "Didukung Dibimbing" dan "harga mulai Rp \[ISI\]", deretan foto candid                                                                | **Lihat program**, **Tanya via WhatsApp**                   |
| 3   | **Program** (inti halaman) | Menampilkan pilihan dan mengantar ke detail     | 4-6 program unggulan sebagai kartu (nama, untuk siapa, durasi, format, harga mulai, tiga hasil utama), filter per bidang, dan tautan "Lihat semua program" ke halaman Daftar program. Satu baris kecil di bawahnya: "Belum yakin? Ngobrol dulu lewat WhatsApp" | **Lihat detail** per program, Lihat semua program, WhatsApp |
| 4   | Kenapa Scareer             | Membangun kepercayaan pada brand                | Dibuka satu kalimat masalah dan solusi. Lalu: kakak tingkat bukan institusi, didukung Dibimbing, kenapa lebih murah (yang dikurangi dan yang tidak, plus "mulai dari Rp \[ISI\], cicilan tersedia"), yang nggak kami janjikan                                  | Lihat program                                               |
| 5   | Cara belajar               | Menjelaskan proses secara umum                  | Empat langkah: pilih program, ngobrol dulu (opsional), belajar bareng mentor, pulang dengan karya                                                                                                                                                              | Lihat program                                               |
| 6   | Bukti: karya dan mentor    | Memperlihatkan hasil dan siapa yang membimbing  | Satu carousel karya (label jujur) dan satu carousel mentor, lintas program. Cerita peserta tampil di sini **hanya jika ada data nyata**                                                                                                                        | Lihat detail program asal                                   |
| 7   | FAQ umum                   | Menjawab keraguan tingkat brand                 | Apa itu Scareer, hubungan dengan Dibimbing, ada jaminan kerja atau tidak, cocok untuk siapa, cara daftar dan cara bayar                                                                                                                                        | **Tanya via WhatsApp**                                      |
| 8   | CTA penutup                | Mengajak bergerak                               | "Bingung mulai dari mana? Ngobrol dulu."                                                                                                                                                                                                                       | **Tanya via WhatsApp**, Lihat program                       |
| 9   | Footer                     | Kontak dan legal                                | Kontak, tautan semua program, kebijakan privasi, syarat dan ketentuan, "didukung Dibimbing"                                                                                                                                                                    | Tautan ke tiap halaman                                      |

**Yang dipangkas dari versi 14 section:** Problem Agitate Solution dilebur ke Hero dan pembuka Kenapa Scareer. Pemilih program dan cerita peserta ditunda sampai ada aturan dan datanya. "Biaya yang jujur" dilebur ke Kenapa Scareer dan kartu Program. Karya dan Mentor digabung jadi satu section.

**Catatan struktur**

1. Section 3 adalah jantung homepage. Section lain mendukungnya.
2. Mobile: bar CTA sticky "Lihat program" setelah Hero keluar layar, hilang saat section Program terlihat.
3. Harga rinci tiap paket hanya ada di halaman detail. Homepage cukup "mulai dari".
4. Section 6 mengambil dari data halaman detail masing-masing program, jadi tidak perlu konten baru.
5. Pemilih program interaktif dan section cerita peserta bisa ditambahkan nanti tanpa mengubah urutan section lain.

## Peta situs ringkas

&#91;embedded content: peta situs · homepage, detail bootcamp, WhatsApp, halaman pendukung\]

Homepage adalah pintu masuk. Karena programnya banyak, ada halaman **Daftar program** (`/program`) dengan pencarian dan filter, dan homepage hanya memajang 4-6 program unggulan yang langsung menaut ke halaman detail. Tiap program punya satu halaman detail `/program/[slug]`. WhatsApp dipakai untuk konsultasi (dari homepage) dan pendaftaran (dari halaman detail).

- **Breadcrumb "Program"** di halaman detail menaut ke halaman Daftar program (`/program`).
- **Filter di Daftar program:** per bidang, level, dan harga. Isi filternya mengikuti data tiap program, jadi tidak perlu diketik ulang.
- **Tentang Scareer** bersifat opsional. Isinya sebagian sudah ada di section Kenapa Scareer.
- Halaman detail yang sudah dibuat (brief, Design-Awesomic.md, wireframe) menjadi **template untuk semua program**. Halaman Daftar program dan homepage memakai kartu program yang sama.

## Keputusan terbuka dan input dari tim

Empat hal pertama mengubah struktur. Sisanya hanya mengisi konten.

| Prioritas | Pertanyaan atau input                                                                                                                                                                          | Mempengaruhi             |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| Tinggi    | **Program apa saja yang ada saat peluncuran, dan mana yang jadi unggulan di homepage?** Jumlahnya sudah dipastikan banyak. Yang dibutuhkan: daftar program dan kriteria memilih yang unggulan. | Section 3, 6, peta situs |
| Tinggi    | **Sudah ada testimoni atau cerita alumni nyata yang boleh dipublikasikan?** Jika belum, bagian cerita di section 6 dibuang.                                                                    | Section 11               |
| Tinggi    | **Pemilih program interaktif dibangun sekarang atau ditunda?** Perlu aturan rekomendasi per program. Kalau tidak, cukup filter dan daftar "cocok untuk siapa".                                 | Section 3                |
| Tinggi    | **Arah UI homepage:** gaya Awesomic atau Visuvate? Rekomendasi: sama dengan halaman detail supaya satu keluarga.                                                                               | Seluruh homepage         |
| Sedang    | Harga mulai yang boleh ditampilkan di homepage, dan apa yang umumnya termasuk di semua program                                                                                                 | Hero, section 3, 4       |
| Sedang    | Nomor WhatsApp dan pesan awal untuk konsultasi                                                                                                                                                 | Hero, FAQ, CTA penutup   |
| Sedang    | Perlu halaman "Tentang Scareer" atau blog?                                                                                                                                                     | Peta situs, footer       |
| Rendah    | Jawaban resmi untuk FAQ tingkat brand (hubungan dengan Dibimbing, jaminan kerja, cara daftar, cara bayar)                                                                                      | Section 7                |

**Langkah berikutnya setelah struktur ini disetujui:** brief detail per section (isi, copy, dan UI), Design.md untuk homepage, dan wireframe, dengan pola yang sama seperti halaman detail bootcamp.
